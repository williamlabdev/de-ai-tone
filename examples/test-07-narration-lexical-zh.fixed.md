# 同一個模型為什麼答案不同（測試稿 07）

同一個模型，換一句話問，答案就會不一樣。這個模型每次只接一個字，那個旋鈕決定它敢不敢亂接。

同一句指示，模型回給你的答案卻不一樣，因為那段指示裡少了一個條件。

我把那些材料放進去，再去找出相關的段落，一個一個帶你看。窗口放不進去的部分，就從頭找到尾重來一遍。

它會產生一段話，給出一個答案，寫在指示裡讓你自己負責，再比對，這份結果可以根據。

模型一個字一個字接出來，拆成更小的塊之後，有一段被拆到兩塊，取樣時是抽，不是挑，這些都是字面用法。桌上放著一顆螺絲、一顆骰子和一顆晶片，旁邊那個模型在跑。
