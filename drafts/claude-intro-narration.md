# 跟著我十分鐘，第一次跟 Claude 對話（旁白草稿・基礎篇）

看完這支影片，我帶你從安裝走到第一次對話。

第一句就卡住，不知道要跟他聊什麼，是最常見的。

Claude 是 Anthropic 做的，你可以把它想成瀏覽器和桌面版都能用的聊天助手。

瀏覽器打開就能用。不過這次我裝桌面版，省得每次開瀏覽器。

先到 claude.ai/download 下載。Mac 跟 Windows 按各自的鈕。

下載完以後，在 Mac 可以直接點選拖拉到應用程式。Windows 版抓下來點兩下裝完，從開始功能表打開。

裝完打開應該會看到登入畫面，沒有的話重開一次。看到就登入，免費版直接就能用。額度用完，畫面會告訴你什麼時候重置。

想知道還剩多少，付費版再點設定裡的使用量。免費版沒有這頁，看畫面通知。

對話記錄在左邊，之前聊過什麼點回去就找得到。開新對話在上面，換題目就開一格新的。

我有提供第一句，直接拿來用。先去說明欄下載我提供的 Prompt，直接貼上。

貼的是幫你寫好的第一句話：我是網路行銷專員，幫我看這份文案哪裡不清楚。

回應出來先看它寫了什麼，對不對得上你的文案。

要深挖一次只追一個點。叫它拿表格整理，對不上的再問一次。

先看改了哪裡，再看為什麼。原文在第幾段，叫它標出來。
