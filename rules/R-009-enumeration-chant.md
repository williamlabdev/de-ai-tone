# R-009 並列三連喊口號 / Parallel chant

## 現象

頓號串起三個同級抽象動賓（`註冊帳號、跑摘要、追來源`），字數相近、動詞同級，靠整齊製造節奏，實為同一層動作換句話說。英文同理：`register, summarize, and follow up`。R-001 只管跨段短句，句內並列歸這條。

逗號版同屬此條：三個等長 declaratives 用 `，` 連接（`左邊是對話記錄，開新對話在上面，常用的資料丟 Projects`），無頓號但同樣排排站。解法同：每句掛目的或拆散。

## Before（禁式）

```text
這支影片我帶你做三件事：註冊帳號、跑一次摘要、追問一次來源。
```

逗號版：

```text
左邊是對話記錄，開新對話在上面，常用的資料丟 Projects。
```

英文：

```text
We help you register, summarize, and follow up.
```

## After（改法）

```text
這支影片我帶你從註冊開始。先貼上第一份資料，跑一次摘要；再追問它根據哪三段下的結論。
```

改法：拆整齊——換動詞層次（開始／貼上／追問），加受詞（第一份資料）與順序詞（先…再…），並用句號與分號把三個動作切成兩個節拍，不再是一句三連。After 本身不得命中本條機械 pattern（0920 前版本命中逗號三連，已改）。

逗號版改法：對話記錄在左邊，隨時點回去看上一輪。開新對話在上面，換題目就開一格新的。（每句掛目的，整齊自散；沒教的 Projects 整句拿掉，見連續性）

英文：

```text
Paste in your first file, get a 300-word summary, then ask which three sections it came from.
```

## 例外

- 具體名詞清單且後文逐項展開的不在此限。
- 有數字編號（第一、第二、第三）的不在此限。
- 問答／因果鏈（如 `用掉多少，還剩多久，上面寫得清清楚楚`）機械會命中，人判放行。
- **冒號引入的技術實體列舉**（`: pass, fail, unknown, and conflict.`／`: provider, model, endpoint, governance profile, agent version, run id.`）機械會命中，人判放行。這是本條英文側最主要的誤殺形狀，見機械段 0926 實測。
- 引用人物原話時保留原樣，加引號。
- 無其他例外。

## 機械檢查可行性

- 可機械化：中文匹配 `(、[^，。！？；、]{1,12}){2,}` 且分段平均 < 6 字，或逗號三連 `([^，。！？；]{4,12}，){2}[^，。！？；]{4,12}[。！]`；英文匹配 `(?:^|[.!?;:]\s+)(?:[^,.!?;]{1,24},\s*){2,}[^,.!?;]{1,24}[.!?]`（3 個以上逗號平行短語，鏈頭鎖在句首、每段 ≤24 字元、收在句尾；0922 英文首次實測發現舊式 `(\b[\w-]+\b[^,.!?;]{0,12},\s*){2,}` 會從長子句中段起算，命中片段像 "handed to it, write code, "，人審看不懂；`\s*` 不可少，否則逗號後空白會斷掉第二段），標記待審。
- 0926 英文實測 FP 率：18 篇英文正本命中 11 處，人讀後只有 1 處是真的（`fill in some boxes, get a diagram, move on.`，三個平行動詞短語），其餘 10 處是冒號引入的名詞列舉，FP 率 91%。
- **試過但放棄的機械收斂**：以「每段平均詞數」當信心分野（仿中文側 `avg>12 字 → [低信心]` 的作法）。實測不可行——真命中那處每段平均 3.0 詞，10 處誤殺分布在 1.2–3.0 詞，兩者完全重疊，任何門檻都切不開。真正的分野是名詞列舉 vs 動詞短語排比，屬語意層，本 repo 不為此加詞性標註。pattern 維持原樣不動（故本次不升 `tone-version`），改以例外條目與本節的 FP 數字讓人判有依據。
- 只能人審的部分：是實質清單（各項有後文展開）還是同層抽象換句話，需人判斷；逗號版先看是否問答／因果鏈，是則放行；英文側先看是否為冒號引入的名詞列舉，是則放行。
