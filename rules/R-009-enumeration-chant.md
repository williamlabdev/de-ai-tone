# R-009 並列三連喊口號 / Parallel chant

## 現象

頓號串起三個同級抽象動賓（`註冊帳號、跑摘要、追來源`），字數相近、動詞同級，靠整齊製造節奏，實為同一層動作換句話說。英文同理：`register, summarize, and follow up`。R-001 只管跨段短句，句內並列歸這條。

逗號版同屬此條：三個等長 declaratives 用 `，` 連接（`左邊是對話記錄，開新對話在上面，常用的資料丟 Projects`），無頓號但同樣排排站。解法同：每句掛目的或拆散。

## Before（禁式）

```text
這支影片我帶你做三件事：註冊帳號、跑一次摘要、追問一次來源。
```

（0.2.21 起機械不報這句：冒號引入、三項 4／5／6 字不同構，歸人判；機械會報的同構形狀如「我們要的是快、準、狠。」「高效、穩定、可靠，這三個字是口號。」）

逗號版：

```text
左邊是對話記錄，開新對話在上面，常用的資料丟 Projects。
```

（0.2.21 起機械不報這句：三節 6／7／12 字不同構，歸人判；機械會報的是三節等長的，如「先切分成列，再挑一個出來，最後比對答案。」這類 5／6／6 字收尾。）

英文：

```text
We help you register, summarize, and follow up.
```

## After（改法）

```text
這支影片我帶你從註冊開始。先貼上第一份資料，跑一次摘要；再追問它根據哪三段下的結論。
```

改法：拆整齊——換動詞層次（開始／貼上／追問），加受詞（第一份資料）與順序詞（先…再…），並用句號與分號把三個動作切成兩個節拍，不再是一句三連。After 本身不得命中本條機械 pattern（0920 前版本命中逗號三連，已改）。

逗號版改法：對話記錄在左邊，隨時點回去看上一輪。開新對話在上面，換題目就開一格新的。（每句掛目的，整齊自散；沒教的 Projects 整句拿掉，見連續性）

英文：

```text
Paste in your first file, get a 300-word summary, then ask which three sections it came from.
```

## 例外

- 具體名詞清單且後文逐項展開的不在此限。
- 有數字編號（第一、第二、第三）的不在此限。
- 問答／因果鏈（如 `用掉多少，還剩多久，上面寫得清清楚楚`）機械會命中，人判放行。
- **冒號引入的技術實體列舉**（`: pass, fail, unknown, and conflict.`／`: provider, model, endpoint, governance profile, agent version, run id.`）機械會命中，人判放行。這是本條英文側最主要的誤殺形狀，見機械段 0926 實測。
- 引用人物原話時保留原樣，加引號。
- **不同構的三連機械不報（0.2.21）**：頓號項或逗號節字數不相同（差 >1）的並列，機械層視為一般散文，不標；若人審覺得仍是口號，自行標 R-009，規則本身不放行。
- 無其他例外。

## 機械檢查可行性

- 可機械化：中文匹配 `(、[^，。！？；、]{1,12}){2,}` 且分段平均 < 6 字，或逗號三連（0.2.21 起兩段都只是候選，實際只標同構短語，見下方 1021 收窄條） `([^，。！？；,.!?;]{4,20}[，,]){2}[^，。！？；,.!?;]{4,20}[。！.!?]`（分隔逗號與句讀同時認全形 `，`／`。！`與半形 `,`／`.!?`；0.2.11 補半形，起因見 R-022 機械段的半形逗號發現——舊 pattern 只認全形，在作者真實語料上低估）；英文匹配 `(?:^|[.!?;:]\s+)(?:[^,.!?;]{1,24},\s*){2,}[^,.!?;]{1,24}[.!?]`（3 個以上逗號平行短語，鏈頭鎖在句首、每段 ≤24 字元、收在句尾；0922 英文首次實測發現舊式 `(\b[\w-]+\b[^,.!?;]{0,12},\s*){2,}` 會從長子句中段起算，命中片段像 "handed to it, write code, "，人審看不懂；`\s*` 不可少，否則逗號後空白會斷掉第二段），標記待審。
- 0926 英文實測 FP 率：18 篇英文正本命中 11 處，人讀後只有 1 處是真的（`fill in some boxes, get a diagram, move on.`，三個平行動詞短語），其餘 10 處是冒號引入的名詞列舉，FP 率 91%。
- **試過但放棄的機械收斂**：以「每段平均詞數」當信心分野（仿中文側 `avg>12 字 → [低信心]` 的作法）。實測不可行——真命中那處每段平均 3.0 詞，10 處誤殺分布在 1.2–3.0 詞，兩者完全重疊，任何門檻都切不開。真正的分野是名詞列舉 vs 動詞短語排比，屬語意層，本 repo 不為此加詞性標註。pattern 維持原樣不動（故本次不升 `tone-version`），改以例外條目與本節的 FP 數字讓人判有依據。
- **1021 中文側收窄（0.2.21，issue #8）**：舊版把任何逗號三連（每節 4–20 字）都標，0929 回掃 learn 全部 zh 旁白腳本命中 2698 處，1021 重掃 135 支命中 3177 處（其中 [低信心] 558），每支都中、量級上不可能逐條人判，等於沒有訊號。William 裁「收窄 pattern：只算同構短語，排除頓號列舉專有名詞／步驟名」。frontmatter 的兩段 regex 維持為候選抓取，同構判定寫在 `tools/review-ui.html` 的 `r009ZhIso()`（不是單行 regex）：(a) 頓號串連首項一起抓，第二項起每項須為純漢字（含拉丁字母／數字的專有名詞與步驟代號不算）、字數相同（差 ≤1）且 ≤6 字，首項取同長尾段；串前 4 字或首項殘段若是 `：`／`:`／包括／分成／分別是／例如／像／比如 引入，視為後文展開的清單不算；(b) 逗號三連逐句切（`。！？；` 為句界），取句尾三節，每節 4–20 字且字數相同（差 ≤1）才標，三節都以「第一／第二／第三」類編號起頭的不標（例外條既有），每節平均 >12 字仍降為 `[低信心]`；match 內須含漢字的 0.2.11 防火牆保留。收窄後 learn 135 支回掃 352 處（[低信心] 20，125 支有命中，平均每支 2.6 處；1021 同日舊版 3177 處），`drafts/` 三支快照 三支 drafts 原本 6 處 R-009 命中（檔頭 human-cleared 已全部人判「非口號」放行）收窄後全部不報，與既有人判一致；examples test-01／test-02 zh 的 .fixed.md 各少一處 R-009（已修稿版本上的誤報），原稿版本來就沒有 R-009 命中；snapshot 以 `--update` 重建基線。頓號首項以同長尾段近似（如「你跟人剩下天氣、工作、還好嗎」首項長度不同構，不報），是已知的漏抓形狀，寧漏不濫。
- 只能人審的部分：是實質清單（各項有後文展開）還是同層抽象換句話，需人判斷；逗號版先看是否問答／因果鏈，是則放行；英文側先看是否為冒號引入的名詞列舉，是則放行（`tools/review-ui.html` 對冒號後起鏈的自動降為 `R-009[en][低信心]`，0.2.11）。
- 工具側兩道防火牆（僅 `tools/review-ui.html`，frontmatter 不變）：中文逗號三連要求 match 內含漢字，純英文逗號鏈只走 en 分支（0.2.11 半形擴充後必須，否則 `register, summarize, and follow up` 會被中文分支重複標記）；英文側冒號後起鏈降信心（上條）。
