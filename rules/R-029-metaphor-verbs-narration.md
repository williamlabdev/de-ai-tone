# R-029 旁白隱喻動詞與擬物名詞 / Metaphorical verbs in narration

## 現象

旁白把平常的動作、東西換成隱喻詞，聽起來像 AI 在「寫」而不是人在「講」：

- `交代`：指示／提示詞（同一句交代、一段交代、交代裡、那段交代、交代也沒換），或當動詞用（交代它做什麼）。
- `交回來`／`交回`：模型回傳結果。
- `拆開帶你看`／`帶你拆給你看`：把「逐項說明」講成拆東西。
- `撈出來`／`撈到`／`撈上來`：檢索。
- `塞進去`／`塞不進去`／`塞滿`：放進 context。
- `判罪`／`定罪`／`審判`／`宣判`：審查語境裡把「判定有問題」寫成法律隱喻（1021 William：「判罪這個就太AI了」）。

次要、信心較低（先當提示，命中標 `[低信心]`）：`一疊`／`那一疊`／`這一疊`（指 context 或材料；真的一疊紙很常見，見例外）、`長出一段話`、`端出`、`自己扛`、`掛在指示／答案／提示裡`、`攤開來對`、`背書`、`可以撐`、`坑`（「這裡有一個坑：…」「坑也在這裡」；1027 William 點名 AI 愛用；火坑／填坑／重踩同一個坑等字面與慣用義人判放行）。

## Before（禁式）

```text
同一句交代，模型交回來的答案卻不一樣。
```

```text
我把那一疊材料塞進去。再去撈出相關的段落，一個一個拆開帶你看。
```

```text
我把這條寫進交代，第七輪就開始拿它判罪。
```

## After（改法）

```text
同一句指示，模型回給你的答案卻不一樣。
```

```text
我把那些材料放進去。再去找出相關的段落，一個一個帶你看。
```

```text
我把這條寫進指示，第七輪就開始照這條挑句子。
```

改法：只換詞，不動句子結構。William 1016 裁定：換字就好，不要重寫整句，重寫反而添 AI 腔。對照表：

| 原詞 | 換成 |
| --- | --- |
| 交代（名詞，指示／提示詞） | 指示 |
| 交代（動詞） | 要它／告訴／設定／寫（看句子） |
| 一疊／那一疊（context、材料） | 那些材料，或直接點名 context |
| 交回來／交回（模型輸出） | 回給你（檢索用回傳／找回來） |
| 拆開帶你看／帶你拆給你看 | 一個一個帶你看 |
| 撈出來／撈到／撈上來 | 找出來／找到／找回來 |
| 塞進去／塞不進去／塞滿 | 放進去／放不進去／裝滿 |
| 長出一段話 | 產生 |
| 端出 | 給出 |
| 自己扛 | 自己負責 |
| 掛在指示／答案裡 | 寫在／附在 |
| 攤開來對 | 比對 |
| 背書 | 當成證據 |
| 可以撐 | 可以根據 |
| 坑（「有一個坑」「坑也在這裡」） | 最常漏的地方／真的會踩到的地方（看句子） |
| 判罪／定罪／審判／宣判 | 照這條挑／判定有問題／算不過 |

## 例外

- 白名單，不命中也不該被改：`接出來`（文字接龍系列的核心隱喻）、`抽`／`挑`（取樣術語）、`拆成更小的塊`（tokenization 的字面用法）、`被拆到兩塊`（chunking 的字面用法）。本條 pattern 不含 `接`、`抽`、`挑`、`拆成`、`被拆`，只認 `拆開帶你看`／`帶你拆給你看`。
- 字面義放行：真的交代任務（交代後事）、真的一疊紙／收據／圖、真的撈東西、真的法庭審判。出現在模型／context／審查語境以外就放行，屬人判。1021 對照裡「疊」約半數是真的一疊收據、一疊報名資料、一疊十二張圖，所以「疊」放低信心組。
- 作者自己留下的核心比喻放行：1019 what-is-generative-ai 作者判「往下長」「長出一段」是該集主軸比喻，留。
- 引用人物原話時保留原樣。
- 其餘無例外。
