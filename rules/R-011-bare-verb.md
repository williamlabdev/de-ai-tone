# R-011 單字動詞無受詞 / Bare verb without object

## 現象

句尾光桿一個單字動詞，後面沒有受詞也沒有補語（`一條一條核。`／`翻回去對。`），聽起來像執法用語或機器指令。雙字（查核、檢查）或帶補語（對上、對完、對回去）即自然，不在此條。

## Before（禁式）

```text
沒標的那些你一樣要能核。
```

```text
表拿回來以後，我教你照著出處翻回去對。
```

英文：

```text
Verified.
```

## After（改法）

```text
沒標的那些你一樣要回去查核。
```

```text
表拿回來以後，我教你驗收。照著它寫的出處翻回去，看每一條是不是真的在原文裡。如果結果一條條對上的話，這張表才能用。
```

改法：單字動詞換雙字（核→查核）或加補語（對→對完／對上）；仍嫌生硬就拆成兩句（點名＋動作＋收尾判斷）。

英文：

```text
Each of the 12 entries matches the source file.
```

## 例外

- 查核、檢核、檢查、審查、校對一律放行（雙字詞）。
- 對上、對完、對不上、對回去放行（帶補語）；對一遍、核三件事放行（有受詞）。
- 引用人物原話時保留原樣，加引號。
- 無其他例外。

## 機械檢查可行性

- 可機械化：中文按句切分，匹配句尾 `[核查對驗審校][。！？]$`，再排除：核前為查／檢、查前為檢、審前為查、對前為上／完／不／去／回／校（正則：`(?<![查檢])核[。！？]$|(?<![檢])查[。！？]$|(?<![上完不去回校])對[。！？]$|(?<![查])審[。！？]$|[驗校][。！？]$`）；英文匹配整句單字 `^(?:Verify|Confirm|Check|Done)\.$`，標記待審。
- 只能人審的部分：是否真無受詞（如「退回去重做」的做有語境受詞，放行）、是否術語固定搭配，需人判斷。機械寧可多標。
