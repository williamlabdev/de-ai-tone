# R-011 單字動詞無受詞 / Bare verb without object

## 現象

分句尾光桿一個單字動詞，後面沒有受詞也沒有補語（`一條一條核。`／`翻回去對。`／`不用理，`／`照樣能跑。`），聽起來像執法用語或機器指令。不限審核類動詞：理什麼、跑什麼、看什麼、貼什麼，只要受詞省掉就算。常見型態是「助動詞＋單字動詞」收尾（不用理／能跑／就貼／自己看）。雙字（查核、檢查）或帶補語（對上、對完、對回去）即自然，不在此條。

## Before（禁式）

```text
沒標的那些你一樣要能核。
```

```text
表拿回來以後，我教你照著出處翻回去對。
```

```text
Node 太舊會印一行警告，不用理，裝完照樣能跑。
```

英文：

```text
Verified.
```

## After（改法）

```text
沒標的那些你一樣要回去查核。
```

```text
表拿回來以後，我教你驗收。照著它寫的出處翻回去，看每一條是不是真的在原文裡。如果結果一條條對上的話，這張表才能用。
```

```text
Node 太舊會印一行警告。那行警告可以略過，因為裝好的 claude 是獨立執行檔，執行時不靠你的 Node。
```

改法：單字動詞換雙字（核→查核）或加補語（對→對完／對上），或把受詞補回來（理→略過那行警告）；仍嫌生硬就拆成兩句（點名＋動作＋收尾判斷）。「不用理」「照樣能跑」這種兩個短句並排的安撫句，除了補受詞還要把「為什麼」講出來，不然只剩信心沒有資訊。

英文：

```text
Each of the 12 entries matches the source file.
```

## 例外

- 查核、檢核、審核、檢查、審查、校對、核對、比對一律放行（雙字詞）；說得對、不對、經驗、學校這類以同字收尾的非動詞也放行。
- 對上、對完、對不上、對回去放行（帶補語）；對一遍、核三件事、看上一輪放行（有受詞）。
- 這張表才能用、拿來用：「用」的受詞是主語本身，放行，機械不列「用」。
- 引用人物原話時保留原樣，加引號。
- 無其他例外。

## 機械檢查可行性

- 可機械化，兩段合併（pattern 以 frontmatter 為準）：(a) 審核類六字 `核查對審驗校` 收在分句尾 `[。！？，；]`，各自排除前一字構成雙字詞的情況（查核／審核／檢查／審查／校對／說得對／經驗／學校…）；(b) 助動詞或方向詞（不用／能／會／就／先／再／去／來／自己／這樣／照著…）緊接一個常見動作動詞（跑理看做改裝弄試填貼問答寫讀搜找抄拆搬測刪存傳丟印跳開關）再收在分句尾。0921 前的版本只有 (a) 且只看句號前，「不用理，」「照樣能跑。」全漏；且 (a) 的「對」排除表誤把「去／回／上／完」當成前一字，連 Before 例句「翻回去對。」都放行了，已修。英文匹配整句單字 `^(?:Verify|Confirm|Check|Done)\.$`。
- 只能人審的部分：(b) 抓不到沒有助動詞的型態（「放進沙箱跑，」的前一字是名詞），要靠人讀；是否真無受詞（如「退回去重做」的做有語境受詞，放行）、是否術語固定搭配，需人判斷。機械寧可多標。

## 適用 profile

- `articles`：嚴格
- `narration`：嚴格（口語也不留光桿單字動詞）

## 出處

- 0922 英文首次實測：en pattern 只收祈使原形，規則自己的 Before 例句 "Verified." 反而抓不到，補過去式。

- 0914 一支 Claude 入門旁白稿的審稿，作者連續兩次糾正：第一次指出問題在動詞不在疊詞（一條一條／一條條皆可）；第二次指出病灶是單字動詞無受詞，「查核」可放行。
- 0921 作者抓到 agent 在對話裡提的候選句「不用理，裝完照樣能跑」：兩個光桿動詞加安撫節拍。當時規則只抓審核類動詞，機械與人審都漏；候選句也沒進審稿流程。規則擴成 (a)+(b)，流程補「候選句也是稿件」。
