# R-027 回聲問句自答 / Echo question

## 現象

段落講到一半插一句問句，問句裡的詞是從前一句抄來的，問完下一句自己接答案，而答案多半也只是把前一句換個說法再講一次：「先把環境音鋪進去，讓畫面有底。**先鋪哪個，先鋪環境音？**因為環境音是底……」、「還有一種最難認。**難認在哪？**沒決定就先叫它寫」、「這兩種它都不會主動跟你說。**它會主動說？**不會，所以自己數」。問句不帶「嗎」「呢」，所以 R-004 抓不到；它也不是在問觀眾，觀眾來不及想，旁白就自己答了。這是修稿在「段內沒問號」的地方湊節奏的痕跡：learn 0911 一輪 AI 感修稿逐段插了這種自問自答，作者在 learn PR #1 連同含「嗎」的反問一起刪掉（issue #9 第 2 型）。

跟 R-004 的分工：含 `嗎|呢|不是嗎|還在等` 的反問歸 R-004，本條只接沒有這些詞的問句。跟 R-012（標題回聲）的分工：R-012 比的是首末句對標題，本條比的是問句對同段前一句。

## Before（禁式）

```text
配音進來之前，先把環境音鋪進去，讓畫面有底。先鋪哪個，先鋪環境音？因為環境音是底，其他聲音都疊在它上面。

表格最常錯在日期欄。錯在哪？錯在它把八月三號讀成三月八號。
```

英文對照（必填）：

```text
Before the voice-over goes in, lay the ambient track first so the picture has a floor. Which goes first, the ambient track? The ambient track, because everything else sits on top of it.
```

## After（改法）

```text
配音進來之前，先把環境音鋪進去，讓畫面有底。環境音是底，其他聲音都疊在它上面。

表格最常錯在日期欄，它把八月三號讀成三月八號。
```

改法只有一種：刪掉問句，把答案直接接在前一句後面；答案若只是前一句的複述（第一段的「環境音是底」已經在前一句講過「有底」），連答案一起併進前一句。不要換成另一個問法，也不要補「嗎」讓它變成反問——那只是從本條搬到 R-004。

英文對照（必填）：

```text
Before the voice-over goes in, lay the ambient track first so the picture has a floor; everything else sits on top of it.
```

## 例外

- 真的在問觀眾的問句放行：問完不自答、或一口氣列出幾個讓觀眾自己想的問題（「可是最新是看發布日期還是版本號？完整還是哪些欄位不能缺？這些沒定義，這五個就不能算對」；「先問它三件事。它把『模型看到什麼』轉到哪一格？它把『模型能動什麼』轉到哪一格？做完之後，它拿什麼證明做對了？」）。機械分不開，人判；1021 learn HEAD 殘留的 3 處全是這型。
- `「」` 引號內的問句（示範提示詞、模型回話、引述他人原話）與「你可以問：…？」「問回去只要一句：…？」這類教觀眾怎麼問的示範句，機械已排除；若引號漏寫而被標到，人判放行。
- 含 `嗎|呢|不是嗎|還在等` 的反問歸 R-004，本條不重複標。
- 段首問句（前面沒有句子可比）不標；段尾問句（後面沒有自答）不標，這是照 issue #9「問完自答」的定義，段尾型的數字見機械段。
- 訪談逐字稿保留受訪者原話時不在此限。
- 標題段、重點條列（`- `／`* `／數字編號起頭的段）不計。

## 機械檢查可行性

- 可機械化（段落級，experimental）：每個正文段（非標題、非清單）以 `。！？；` 切句（保留句尾標點）。對每個以 `？` 結尾的句子 Q：
  1. Q 含 `嗎|呢|不是嗎|還在等` 跳過（歸 R-004）；Q 在 `「」` 引號內（承接前句未閉的 `「`，或 Q 自己開了 `「` 沒閉）跳過；Q 含 `問…：`（`問[^，。？]{0,8}[：:]`）跳過。
  2. Q 是段首句跳過（沒有前一句可比）；Q 是段尾句跳過（沒有自答，見 issue #9 第 2 型定義）。
  3. 取同段前一句 P。先把 Q 裡的功能詞挖掉（停用清單 `R027_STOP`，含 `這個`／`那個`／`我們`／`你們`／`他們`／`可以`／`就是`／`不是`／`什麼`／`怎麼`／`這樣`／`那樣`／`一個`／`一下`／`的話`／`然後`／`所以`／`但是`／`因為`／`如果`／`還是`／`或者`／`已經`／`沒有`／`知道`／`覺得`／`需要`／`應該`／`時候`／`東西`／`問題`／`事情`／`地方`，與語料上看到的 `這裡`／`哪個`／`哪些`／`為什麼`／`其實`／`現在`／`這種`／`自己`／`大家`／`有沒`／`是不`／`要不`／`會不`／`不會`／`不能`／`可能`／`也是`／`都是`／`而且`／`只是`／`只有`／`你會`／`你要`／`你的`／`它把`／`你把`／`出來`／`起來` 等；完整清單以 `tools/review-ui.html` 為準），剩下的連續漢字段再找 P 也含有的、長度 >= 2 的子串，取最長者當關鍵詞。
  4. 有關鍵詞即標 `R-027[experimental]`，why 列出 Q（截 40 字）與關鍵詞，一段只標一次。
- 不是單行 regex（要跨句比對），frontmatter 寫判定描述並標 `mechanical_type: prose`，可執行版是 `tools/review-ui.html` 的 `r027EchoQ()`／`r027Keyword()`；`opts.noFollow` 只供校準統計（不要求後面有句子），掃描不用。
- 1021 中文校準（learn 旁白稿 `topics/*/script.zh.md`，剝 HTML 註解後掃，`##` 與清單不算段；語料不入 repo）：
  - 病例：learn PR #1（`b03086f~1`，0911 插入的回聲問句尚未刪）131 支 4,710 段，命中 **31 處／15 支**；其中 **30 處作者在 PR #1 刪掉**（14 支），1 處留下（methodology-landscape 三題真問句）。issue #9 當時估「約 37 候選／22 支」，同一量級（不排除引號內問句時是 45 處／23 支）。
  - 對照：1021 learn HEAD 135 支 4,716 段，命中 **3 處／3 支**（failure-detection、methodology-landscape、vibe-coding-limits-claude），三處都是作者兩輪裁定後留下的真問句（列舉待觀眾自己想的問題），人判全部放行；HEAD 是作者裁完的語料，殘留命中照定義就是誤標，誤標率以此計 3／3。
  - 抽樣人讀（病例 20 處）：作者刪掉的那型都是「問句複述前一句一個詞，下一句自答」：「難認在哪？沒決定就先叫它寫」「真的講過？不一定，它補的」「誰能決定？不只你一個人」「出事在哪裡？出在簽的那個人看不懂」「那要多告訴它什麼？指名哪一段不對」「形狀講死有什麼好？落落長的說明直接消失」。誤標在加排除前有兩型：引號內的模型回話／示範提示詞（「要不要順便加上刪除成員的按鈕？」，9 處，已機械排除）與真問句列舉（3 處，留人判）。
  - 召回：PR #1 刪掉的無「嗎」問句共 143 句，本條抓到 25（17%）。漏的三類：段首問句 18、段尾無自答 20、問句與前一句沒有 >= 2 字共用關鍵詞 80——後者多為極短問句（「核什麼？」「改幾個字？」「聽完帶走什麼？」）或「差在哪裡？差在怕重跟怕吵…」「問題出在哪？出在位置」這種**答句複述問句開頭**的型態（9 處）。這兩型要另一種訊號（答句前綴回聲、或問句字數門檻），本條不涵蓋，記為已知邊界。
  - 不要求「問句後面同段還有句子」時：病例 57 處／30 支（作者刪 53、留 4）、對照 6 處；比要求自答多抓 20 處真陽性、多 3 處誤標。先照 issue #9「問完自答」的定義要求後句，這組數字留著等作者裁要不要放寬。
- 只能人審的部分：問句是真的在問觀眾還是修稿插的回聲；引號漏寫時的引述句；答句複述問句開頭的型態（機械不抓）。
- 本條 n 小（病例只有一輪修稿的產物、對照只有一個頻道），停用詞清單部分是看過命中後補的，有過擬合風險，維持 experimental；命中標 `[experimental]`，先當提示不當結論。
