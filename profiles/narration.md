# Profile：narration（影片旁白，口語例外）

旁白允許什麼、文章不允許什麼：

- R-001：允許最多兩句短句連用，第二句必須帶資訊（時間、數字、動作）。
- R-002：允許一次對比錨點，超過一次改直述。
- R-003：允許用破折號標停頓，一支片最多兩處；機械仍按段標記，人判看全片累計。
- R-004：與文章同樣嚴格，不靠反問收尾，用行動句收尾。
- R-005：片尾標語允許一句金句，正文不允許。
- R-006：允許一次第二人稱，且須帶資訊（時間、數字、動作）；預言感受（懂／後悔／愛上）不允許。
- R-007：與文章同樣嚴格，口語也不留裸倍數。
- R-008：與文章同樣嚴格，口語也不用空倒數催促。
- R-009：與文章同樣嚴格，口語三連同樣是喊口號；具體名詞清單且後文展開的除外。
- R-010：與文章同樣嚴格，人不先宣告。
- R-011：與文章同樣嚴格，口語也不留光桿單字動詞（核→查核，對→對上／對完）。

原則：口語例外只放寬「節奏」，不放寬「資訊密度」。凡是放寬處仍須補數字或動作。

## 帶做口氣（0914 旁白稿實證）

教學旁白是帶著觀眾一步步實作，不是預告也不是回顧。只進 profile 範例，不進 rules 機械條：

- 主語用第一人稱帶做（我會帶你／我們先…再…），不用第二人稱預告（你會…）。開頭用「看完這支影片」，不用「這集走完」。
- 步驟用流程帶（從…再…／先…再…最後…），不寫死幾件事、不數數，兩件五件都通。
- 指令用動作句（你把檔案拖進去、照著出處翻回去），不用名詞喊（交代、對照表、驗收作動詞）。
- 一次只給一個動作；收尾落在一個判斷上（如果結果一條條對上的話，這張表才能用）。
- 介紹期只講是什麼，不帶動作；一句帶一句，不排比一次倒完。
- 痛點是第一層：先講觀眾最先卡住的地方；文要對題，故事還給它該在的段。
- 出處：0914 一支 Claude 入門旁白稿「你會帶走什麼」段的第四版改寫（作者原句）。
- 用詞只用受訪者本人的話（interviewer 收進語料檔的原句詞彙，不替他換同義詞）；沒料不編，標 `[待補]`，沒重跑的寫通用加旁白自陳（0914 一支旁白稿定下的誠實邊界）。
- 標題承諾要撐得住：`十分鐘`為系列概念，不按實際片長拿掉（超 12 分鐘保留），版號不唸（易過期），數字先查證。
