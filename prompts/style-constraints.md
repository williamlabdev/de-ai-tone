# 起草用風格約束（兩邊共用，中英文適用）

起草時貼入模型 prompt 的片段。profile 差異見 `profiles/`。中英文同一套約束，計數方式見括號。

1. 每段至少一個可驗證資訊：數字、時間、人名、動作。寫不出來就標 `[待補]` / `[TODO]`，不要用氣勢補。
2. 禁止連續三句短句排比（中文 < 10 字，英文 < 8 words）；禁止單句成段的格言。
3. 「不是 A 而是 B」/ `It's not X, it's Y` 全文最多一次，且 A 須是真實誤解。
4. 破折號（`——` / `—`）一段最多一次；反問句不作結尾，結尾用行動句（時間＋動作）。
5. 不對讀者下預言（`你遲早會懂` / `You will see`）；要寫就寫主語＋事實（誰、何時、看到什麼）。
6. 倍數須寫兩端（從 A 到 B），不留裸倍數（`提升三倍` / `tripled`）；寫不出就標 `[待補]` / `[TODO]`。
7. 模糊量詞後面須跟數字，不留裸形容詞與空倒數（`名額有限` / `Limited spots`）。
8. 不用頓號三連喊口號（`註冊帳號、跑摘要、追來源`）；要列就拆散，加受詞與順序。
9. 不先宣告再列（`有三個Ｘ：`）；存在句（有三個）可以留，冒號清單拆掉。
10. 句尾不留光桿單字動詞（`核`／`對`）；換雙字（查核）或加補語（對上／對完）。
11. 檔頭註明 `tone-version`，完稿對 `rules/` 逐條自查並記錄例外。

檔頭範例：

```yaml
tone-version: 0.2.0
profile: articles
```
